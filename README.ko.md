# 창 가림 (Window Veil)

[English](README.md)

창 가림은 고른 프로그램의 창을 **쓰지 않을 때만** 덮어 주는 Windows 트레이 프로그램입니다.

자리 옆을 지나가는 사람에게는 메신저 대화나 메일 대신 가림이 보입니다. 그 창을 클릭하거나 그 창으로 넘어가면 가림이 걷힙니다.

옆 사람의 시선을 막아 주는 도구일 뿐, 프로그램을 잠그거나 내용을 암호화하지는 않습니다. 화면 캡처나 화면 공유도 막지 않습니다.

## 할 수 있는 것

- **고른 프로그램 가리기**
  다른 창을 쓰는 동안 고른 프로그램의 창을 덮습니다. 창을 옮기거나 크기를 바꾸면 가림도 따라가고, 그 창 앞에 있는 다른 창은 덮지 않습니다.

- **잠깐 보기**
  덮인 창 위에 마우스를 올리고 **Ctrl** 을 누르고 있으면 잠깐 보입니다.

- **가림 모양 바꾸기**
  흐림, 빈 터미널, 로그가 올라가는 터미널, 빈 메모장, 빈 표, 직접 고른 그림 중에서 고릅니다. 기본 모양에는 가짜 내용만 들어 있어서, 무언가 가려져 있다는 것 자체를 알아채기 어렵습니다.

- **일부만 보이게 두기**
  입력칸처럼 창의 일부는 가리지 않고 보이게 둘 수 있습니다.

- **어떤 앱에서 알림이 왔는지 알려주기**
  가리고 있는 앱에 Windows 알림이 오면 "Discord 새 알림"처럼 앱 이름과 건수만 알려 줍니다. 내용은 보여 주지 않습니다.

- 모니터마다 화면 배율이 달라도 정확히 덮습니다.

- Windows 표시 언어에 따라 한국어 또는 영어로 나옵니다.

## 설치

[Releases](https://github.com/cooingpop/window-veil/releases) 에서 최신 버전을 받습니다. Windows 11 용이고, 따로 설치할 것은 없습니다.

| 받을 파일 | 이럴 때 | 시작하는 법 |
|---|---|---|
| `WindowVeil-Setup-…-win-x64.exe` | 보통처럼 설치해서 쓸 때 | 설치한 뒤 시작 메뉴에서 **Window Veil** 을 엽니다. |
| `WindowVeil-…-win-x64.zip` | 설치 없이 쓸 때 | 압축을 풀고 `WindowVeil.exe` 를 실행합니다. |

창 가림은 작업 표시줄 오른쪽에 **방패 아이콘**으로 떠 있습니다. 안 보이면 작업 표시줄 오른쪽 끝의 **^** 를 눌러 보세요.

## 쓰는 법

1. 방패 아이콘을 누릅니다.

2. **가릴 프로그램 고르기** 에서 가릴 프로그램을 체크합니다.
   메뉴가 닫히지 않으니 여러 개를 이어서 체크할 수 있습니다.

3. **가린 창 꾸미기** 에서 프로그램을 고르면 가림 모양, 보이게 둘 영역, 알림을 정할 수 있습니다.

4. 가려진 프로그램을 쓰려면 그 창을 클릭하거나 그 창으로 넘어갑니다.
   넘어가지 않고 잠깐만 보려면 마우스를 올리고 **Ctrl** 을 누르고 있습니다.

메뉴 아래쪽에는 **사용법 보기**, **모든 가림 잠시 끄기**, **창 가림 끝내기** 가 있습니다.

## 알림

Windows 알림 배너는 Windows 가 모든 창보다 위에 그립니다. 그래서 창 가림이 덮을 수 없습니다.

창 가림이 배너를 대신 끌 수도 없습니다. 이 설정은 Windows 설정 앱에서 바꾼 것만 Windows 가 받아들이기 때문입니다.

그래서 창 가림은 이렇게 합니다.

- 가리고 있는 앱에 Windows 알림이 오면, 오른쪽 아래에 **"앱 이름 새 알림"** 과 건수만 띄웁니다. 누르면 그 앱으로 넘어갑니다. 그 앱을 쓰고 있을 때는 띄우지 않습니다.

- 가리고 있는 앱의 알림 배너가 아직 켜져 있으면, 메뉴 맨 위에 빨간 글씨로 알려 줍니다. 그 줄을 누르면 Windows 설정에서 배너를 끄는 방법이 나옵니다. 안내 창은 지금 상태를 보여 주다가, 배너가 꺼지면 초록색으로 바뀝니다.

배너 끄기는 **PC 마다 앱별로 한 번**이면 됩니다. 창 가림을 다시 설치해도 Windows 가 이 설정을 그대로 기억합니다. 알림은 Windows 알림 센터에 그대로 남습니다.

카카오톡처럼 Windows 알림 대신 자기 팝업 창을 띄우는 앱은 이 작업이 필요 없습니다. 그 팝업도 그 앱의 다른 창처럼 가려집니다.

## 언어

Windows 표시 언어가 한국어면 한국어로, 그 밖에는 영어로 나옵니다.

언어를 직접 정하고 싶으면 환경 변수 `WINDOWVEIL_LANG` 을 `ko` 또는 `en` 으로 정한 뒤 창 가림을 다시 켜세요.

```powershell
setx WINDOWVEIL_LANG ko
```

## 개인정보

창 가림은 PC 안에서만 동작하고 어디로도 아무것도 보내지 않습니다. 창 제목이나 화면 내용은 저장하지 않습니다.

설정은 `%APPDATA%\WindowVeil` 에 저장합니다.

| 파일 | 들어 있는 것 |
|---|---|
| `targets.txt` | 고른 프로그램, 가림 모양(그림을 골랐다면 그 파일 위치), 알림 신호를 끈 프로그램 |
| `areas.txt` | 보이게 둘 영역의 위치 |
| `veil.log` | 문제 확인용 기록. 프로그램 이름이 들어갈 수 있으니 이슈에 올리기 전에 한 번 확인해 주세요. |

알림 신호를 위해 창 가림이 읽는 값은 둘뿐입니다. Windows 가 앱마다 `HKCU\Software\Microsoft\Windows\CurrentVersion\Notifications\Settings` 아래에 적어 두는 **마지막 알림 시각**과 **배너가 꺼져 있는지**입니다. 알림 내용은 읽지 않고, Windows 설정도 바꾸지 않습니다.

프로그램을 지워도 이 파일들은 남습니다. 지우려면 창 가림을 끝낸 뒤 `%APPDATA%\WindowVeil` 폴더를 지우세요.

## 알아둘 점

- **가림은 나에게도 보입니다.**
  보안필름처럼 보는 각도로 막는 것이 아닙니다. 가려진 창을 보려면 Ctrl 로 잠깐 보거나 그 창으로 넘어가세요.

- **보이게 둔 영역은 누구에게나 보입니다.**
  예를 들어 입력칸에 써 둔 글은 지나가는 사람도 볼 수 있습니다.

- **화면 공유에는 가림이 그대로 나옵니다.**
  회의 중 화면을 공유하면 상대에게도 가림이 보입니다.

- **잠금 장치가 아닙니다.**
  누군가 내 키보드와 마우스를 쓰면 그 프로그램을 열 수 있습니다.

- **Windows 알림 센터에는 알림 내용이 그대로 남습니다.**

Windows 11 에서 카카오톡, Discord, Whale 로 확인했고, 화면 배율이 다른 모니터에서도 확인했습니다.

아직 확인하지 않은 것: Windows 10, Microsoft Store 앱, 「항상 위」 로 설정된 창, 화면 배율이 다른 모니터 사이로 창을 끌어 옮기는 도중.

## 직접 빌드하기

Windows 에 기본으로 들어 있는 C# 컴파일러(.NET Framework 4.x)로 빌드합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

`dist\WindowVeil.exe` 가 만들어집니다.

설치 파일을 만들려면 [Inno Setup 6](https://jrsoftware.org/isinfo.php) 을 설치하고 다음을 실행합니다.

```powershell
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" "/DAppVersion=$((Get-Content VERSION).Trim())" installer\WindowVeil.iss
```

빌드 없이 빠르게 시험할 때는 `run-hidden.vbs` 를 실행합니다. `run.ps1` 이 켜질 때마다 `src\Veil.cs` 를 PowerShell 안에서 컴파일해서 실행합니다.
